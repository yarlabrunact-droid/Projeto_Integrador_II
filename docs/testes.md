# Registro de Testes

## 1. Objetivo

Os testes tiveram como objetivo verificar o funcionamento das principais telas e funcionalidades do protótipo "Eu Não Tô Bem — Sistema Inteligente de Prevenção da Sobrecarga Estudantil".

## 2. Ambiente de teste

- Sistema operacional: Windows
- Framework: Flutter
- Linguagem: Dart
- Editor: Visual Studio Code
- Ambiente de execução: Microsoft Edge
- Versão do protótipo: v1.0.0

## 3. Testes realizados

| Código | Teste | Resultado |
|---|---|---|
| T01 | Abertura do sistema | Aprovado |
| T02 | Tela de login | Aprovado |
| T03 | Cadastro de usuário | Aprovado |
| T04 | Navegação entre as telas | Aprovado |
| T05 | Cadastro de atividade | Aprovado |
| T06 | Exibição do indicador de carga acadêmica | Aprovado |
| T07 | Exibição de alertas e sugestões | Aprovado |
| T08 | Calendário de atividades | Aprovado |
| T09 | Área de apoio | Aprovado |
| T10 | Painel institucional | Aprovado |
| T11 | Informações relacionadas à privacidade | Aprovado |
| T12 | Execução final do protótipo | Aprovado |

## 4. Validação

Durante a validação, as principais telas do sistema foram acessadas e as funcionalidades implementadas foram executadas para verificar seu comportamento.

Foram verificadas a navegação, o cadastro de atividades, a apresentação da carga acadêmica, o calendário, os alertas, as sugestões de organização, a área de apoio e o painel institucional.

## 5. Observações

Os testes realizados correspondem à validação do protótipo desenvolvido.

Para uma futura versão destinada à utilização em ambiente real, seriam necessários testes adicionais envolvendo:

- autenticação real;
- persistência de dados;
- banco de dados;
- segurança;
- controle de acesso;
- anonimização;
- desempenho;
- compatibilidade com diferentes dispositivos;
- testes com usuários em maior escala.

## 6. Resultado final

O protótipo apresentou funcionamento adequado durante os testes realizados, permitindo a navegação pelas principais áreas e a utilização das funcionalidades implementadas.
