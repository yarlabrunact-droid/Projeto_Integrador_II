# Documento de Requisitos

## 1. Requisitos Funcionais

### RF01 — Cadastro e Login

O sistema deverá permitir que o estudante crie uma conta e realize login.

### RF02 — Cadastro de Atividades

O sistema deverá permitir o cadastro de provas, trabalhos, apresentações, projetos e outras atividades acadêmicas.

### RF03 — Calendário Acadêmico

O sistema deverá apresentar as atividades cadastradas em formato de calendário.

### RF04 — Registro da Rotina

O sistema deverá permitir que o estudante registre informações relacionadas à sua rotina acadêmica.

### RF05 — Indicador de Carga Acadêmica

O sistema deverá calcular um indicador de carga acadêmica com base nas informações cadastradas.

### RF06 — Identificação de Períodos Críticos

O sistema deverá identificar períodos com concentração elevada de atividades.

### RF07 — Previsão de Alta Carga

O sistema deverá analisar as atividades futuras e identificar possíveis semanas de alta carga acadêmica.

### RF08 — Alertas

O sistema deverá emitir alertas quando identificar uma concentração elevada de atividades.

### RF09 — Sugestões de Organização

O sistema deverá apresentar sugestões para auxiliar o estudante na organização das atividades.

### RF10 — Histórico

O sistema deverá permitir que o estudante visualize a evolução de sua carga acadêmica ao longo do tempo.

### RF11 — Painel Institucional

O sistema deverá disponibilizar um painel para usuários institucionais autorizados.

### RF12 — Dados Anônimos

O painel institucional deverá apresentar dados agrupados e anonimizados.

### RF13 — Identificação de Padrões

O sistema deverá permitir a visualização de tendências e períodos de maior carga acadêmica.

### RF14 — Área de Apoio

O sistema deverá disponibilizar informações sobre os canais de apoio da instituição.

## 2. Requisitos Não Funcionais

### RNF01 — Usabilidade

O sistema deverá possuir uma interface simples, intuitiva e adequada ao público estudantil.

### RNF02 — Responsividade

O sistema deverá funcionar adequadamente em computadores, tablets e smartphones.

### RNF03 — Segurança

O sistema deverá proteger os dados dos usuários.

### RNF04 — Privacidade

O sistema deverá preservar a identidade dos estudantes nas informações apresentadas à instituição.

### RNF05 — Controle de Acesso

O sistema deverá permitir que informações institucionais sejam acessadas somente por usuários autorizados.

### RNF06 — Compatibilidade

O sistema deverá funcionar nos principais navegadores atuais.

### RNF07 — Transparência

O sistema deverá informar ao usuário quais dados são coletados e para qual finalidade serão utilizados.

## 3. Regras de Negócio

### RN01 — Indicador de Carga

O indicador deverá considerar a quantidade e a concentração das atividades acadêmicas.

### RN02 — Período Crítico

O sistema deverá classificar como período crítico aquele que atingir os critérios de carga definidos pela equipe.

### RN03 — Anonimização

Os dados apresentados à instituição deverão ser agrupados e anonimizados.

### RN04 — Não Diagnóstico

O sistema não deverá realizar diagnóstico médico ou psicológico.

## 4. Restrições

- O sistema não deverá substituir profissionais da área de educação ou saúde.
- Os dados individuais dos estudantes não deverão ser expostos no painel institucional.
- O sistema deverá utilizar somente os dados necessários para suas funcionalidades.
